## Pertemuan 4 — Design token halaman To-Do List

- Berkas gaya yang akan dibuat: tokens.css, base.css, layout.css, komponen.css, tema.css
- Warna utama: #F3B8B8 (pastel pink), dipilih karena memberikan kesan cute, lembut, dan nyaman dilihat, serta dipadukan dengan pastel blue dan cream.

### Token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #F3B8B8 | tombol, tautan, penanda |
| --color-fg | #3B3835 | warna teks utama |
| --color-bg | #FFF8EF | latar halaman |
| --color-surface | #FFFFFF | latar kartu dan panel |
| --color-border | #E8DDD1 | garis pemisah dan tepi kotak |
| --color-danger | #D98282 | peringatan dan isian yang tidak sah |
| --color-focus | var(--color-primary) | garis fokus papan ketik |
| --radius-md | 0.5rem | sudut tombol dan kartu |
| --space-4 | 1rem | jarak standar antar elemen |

Kriteria selesai saya: mengubah --color-primary di satu baris harus mengubah warna tombol, tautan, judul, dan garis fokus.
