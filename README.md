## Pertemuan 3 — Halaman profil saya
 
Topik halaman saya:  To do list aktivitas keseharian
 
- Judul halaman: To do list aktivitas keseharian
- Deskripsi: Daftar aktivitas keseharian itu apa aja, mana yang harus di prioritaskan penyelesaiannya
- Tautan navigasi: 1. Daftar aktivitas harian   2.  Tambah aktivitas    3.Tentang saya
- Dua bagian utama: 1. Daftar aktivitas hari ini           2.Tambah aktivitas baru
- Kolom tabel: Nama aktivitas, waktu, tenggat, prioritas, status
- Kolom form: Nama aktivitas, waktu, tenggat, prioritas
- Gambar: todo-list.webp

## Pertemuan 4 — Design token halaman profil
 
- Berkas gaya yang akan dibuat: tokens.css, base.css,
  layout.css, komponen.css, tema.css
- Warna utama: #9CCBE8 (pastel blue) , dipilih karena saya temanya pastel
 
### Token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #9CCBE8 | tombol, tautan, penanda |
| --color-fg | #303B4A | warna teks utama |
| --color-bg | #F7F5FA | latar halaman |
| --color-surface | #FFFFFF | latar kartu dan panel |
| --color-border | #E3DDE8 | garis pemisah dan tepi kotak |
| --color-danger | #E8A6B5 | peringatan dan isian yang tidak sah |
| --color-focus | #C8B6E2 | garis fokus papan ketik |
| --radius-md | 0.5rem | sudut tombol dan kartu |
| --space-4 | 1rem | jarak standar antar elemen |

Kriteria selesai saya: mengubah --color-primary di satu baris
harus mengubah warna tombol, tautan, judul, dan garis fokus.
